# ERA FieldOPS site

Static site served by GitHub Pages (`.nojekyll`, so `_prototypes/` is live but unlinked).

## Videos

When asked to look at, arrange or rearrange the YouTube videos, follow `videos/README.md`:
the user pastes links into `videos/links.txt`, a GitHub Action fills `videos/catalog.json`
(plus `thumbs/` and `transcripts/`), and you arrange them by writing `videos/layout.json`.
YouTube may be unreachable from your sandbox — the catalog is how you see the videos.
