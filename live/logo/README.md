# ERA Live — logo

The mark is an **E built from video tiles**: one tall camera and three stacked beside it, the
way a multi-camera wall looks. The middle one is red: that camera is on air.

| File | Use |
| --- | --- |
| `era-live-logo-dark.svg` / `.png` | logo on dark backgrounds |
| `era-live-logo-light.svg` / `.png` | logo on light backgrounds (print, documents) |
| `era-live-mark-dark.svg`, `era-live-mark-light.svg` | the mark alone, where the name is already written |
| `era-live-icon.svg`, `-512.png`, `-180.png` | app icon / favicon |
| `era-live-og.jpg` | link preview image (WhatsApp, Facebook, etc.) |

Colours: red `#FF3B30`, light `#ECECED`, dark `#111112`, grey `#A1A1A6` / `#6E6E73`.
Keep the red only on the middle tile, and leave free space around the logo at least as
wide as the mark's tall tile.

The wordmark is set in **Satoshi** by Indian Type Foundry (fontshare.com), converted to outlines,
so the logo looks the same everywhere without the font installed.
