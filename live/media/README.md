# ERA Live — landing page imagery

Illustrative AI-generated stills for the ERA Live landing page: one gymnastics
competition with a camera at every apparatus, plus the whole arena. `beam` and
`floor` come from Higgsfield (Cinema Studio Image 2.5), the rest from Figma AI
image generation. The page labels them "Imagini ilustrative".

| File | Shown as |
| --- | --- |
| `beam` | camera 01, balance beam (Bârnă) |
| `floor` | camera 02, floor (Sol) |
| `bars` | camera 03, uneven bars (Paralele inegale) |
| `vault` | camera 04, vault (Sărituri) |
| `rings` | camera 05, rings (Inele) |
| `pommel` | camera 06, pommel horse (Cal cu mânere) |
| `arena` | the full-width band under the camera wall |

Each comes in two widths: the original (1920, 1536 or 1792 px wide) and a
smaller one for phones (`-960`, or `-1200` for the arena). They are WebP,
quality 88 for the originals and 86 for the small ones.
