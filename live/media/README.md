# ERA Live — landing page imagery

Illustrative stills for the ERA Live landing page, generated with Higgsfield
(Cinema Studio Image 2.5): one gymnastics event seen from four camera angles,
plus the empty arena with three broadcast cameras. The page labels them
"Imagini ilustrative".

| File | Shown as |
| --- | --- |
| `cam1` | camera 01, side |
| `cam2` | camera 02, from behind |
| `cam3` | camera 03, backlit |
| `cam4` | camera 04, from above |
| `arena` | the full-width band under the camera wall |

Each comes in two widths (`-960` / `-1200` for small screens). They are WebP,
exported from the 2K originals at quality 86–88.
